# 12. Glossarium

## Architectuur- en documentatietermen (specifiek voor dit arc42-document)

| Term | Betekenis |
|---|---|
| arc42 | Het sjabloon waarop `docs/arc42` is gebaseerd — 12 vaste hoofdstukken voor software-architectuurdocumentatie. |
| C1 / C2 / C3 | De eerste drie C4-abstractieniveaus: systeemcontext, containers, componenten. Zie `docs/likec4`. |
| LikeC4 | De tool waarmee het C4-model als tekst (`.c4`-bestanden) is vastgelegd en gerenderd. |
| Module, interface, seam, adapter, diep/ondiep, leverage, locality | Architectuurvocabulaire uit de `/codebase-design`-skill, gebruikt in de architectuurreview (deliverable 1) en in hoofdstuk 5/11 van dit document. |
| ADR (Architecture Decision Record) | Een vastgelegde architectuurbeslissing, zie `docs/adr`. |
| SBOM (Software Bill of Materials) | Machineleesbare lijst van alle (transitieve) afhankelijkheden; wordt uitgewerkt in deliverable 5. |
